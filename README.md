# MG3
## Devlog
1. The default values are:
floats: 0.0f (shows up as 0 but floats have the f in front)
ints: 0
bools: false
strings: "" (empty string, null)
2. The update method is called every frame automatically. It doesn't have to be called manually.
3. The TimerText class uses the timer setting the timer to an initial value, then every frame (through the update method) it reduces the timer and sets the timer text to whatever the timer number is.
